📊 Sales & Profit Performance Dashboard – Power BI
📌 Project Overview

This project is a Sales & Profit Analysis Dashboard built using Power BI. The dashboard provides insights into regional performance, category-wise sales, product trends, and profitability using a sales dataset (INR).

The goal of this project is to analyze business performance and generate meaningful insights for decision-making.

📂 Dataset Used

The dataset contains the following fields:

Order Date

Region

Category

Product Name

Sales (INR)

Profit (INR)

Price

Quantity

🛠️ Steps Performed
1️⃣ Data Preparation

Imported dataset into Power BI

Checked data types and cleaned inconsistencies

Created DAX Measures:

Total Sales

Total Profit

Profit Margin

Total Quantity

2️⃣ Visualizations Created

✔ Sales by Region (Donut Chart)
✔ Sales & Target Comparison (Area/KPI Visual)
✔ Sales by Category (Pie Chart)
✔ Category-wise Sales (Bar Chart)
✔ Product-wise Sales Trend (Line Chart)
✔ Profit by Category & Product (Treemap)

📊 Key Insights

Electronics category generates highest sales (17.31M INR).

North region contributes highest revenue.

Profitability varies across categories.

Few products contribute major share of total sales.

Sales show gradual variation across products.

🎯 Business Recommendations

Focus marketing efforts on high-performing regions.

Improve margin strategies in lower-performing categories.

Promote top-selling products to maximize revenue.

Optimize underperforming product pricing.

Power BI Desktop
